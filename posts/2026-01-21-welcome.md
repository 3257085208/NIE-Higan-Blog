这是 **NIE-Higan-Blog** 的演示正文。

## 它能做什么

- Markdown 写作，Python 一键构建
- 文章 / 说说 / 友链 / 留言板
- Tabs、ANSI 终端块、暗色主题
- 构建期 SEO（meta / RSS / sitemap / prev-next）

## 快速开始

```bash
pip install -r requirements.txt
export SITE_URL='https://example.com'
python build.py
```

把 `dist/` 丢到任意静态托管即可。
